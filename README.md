# innowise-de-lab-aug-2025\_-Anna\_Naumova-.



Название проекта: \*\*EcoMarket\*\* учебный проект по Data Engineering в рамках Innowise Big Data Lab.



Цель проекта: создать централизованную Data Platform для компании EcoMarket, которая позволит видеть полную картину бизнеса: от динамики и структуры продаж до ключевых показателей эффективности (\*\*KPI\*\*) и сравнения магазинов между собой.



Источники данных: В качестве источников данных использовались CSV-файлы.



Данные описывают бизнес-процесс продаж продуктовой сети и включают информацию о:



* продажах;
* товарах;
* категориях товаров;
* клиентах;
* сотрудниках;
* магазинах;
* городах;
* странах.



Целевое хранилище:  \*\*PostgreSQL\*\*.



Как запустить ваш проект: 



1\.Запустить PostgreSQL в Docker.

2\.Открыть DBeaver и подключиться к базе данных PostgreSQL.

3\.Выполнить SQL-скрипты для создания схем и таблиц.

4\.Запустить Python-скрипты для загрузки и обработки данных.

5\.Выполнить скрипты для проверки качества данных.

6\.Создать Gold Layer и Data Marts.

7\.Открыть Power BI и подключиться к PostgreSQL.

8\.Построить дашборд на основе подготовленных витрин данных.
